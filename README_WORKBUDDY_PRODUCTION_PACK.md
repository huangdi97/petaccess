# WorkBuddy Production Launch Pack

## 用法

把本包文件复制到当前项目根目录：

- WORKBUDDY_PRODUCTION_MASTER_GOAL.md
- WORKBUDDY_PRODUCTION_START_PROMPT.md
- PRODUCTION_ACCEPTANCE_MATRIX.md
- UI_UX_IMPLEMENTATION_SPEC.md
- LAUNCH_READINESS_CHECKLIST.md
- PRODUCTION_STATE.md

然后在 WorkBuddy 中发送：

`WORKBUDDY_PRODUCTION_START_PROMPT.md`

全文。

## 注意

这是当前项目的“生产上线总路线”，不是 starter。

执行顺序：

Review/Publish
→ 30–50 Real Data
→ UX Freeze
→ UI/Frontend
→ Admin
→ Providers
→ Backend Hardening
→ Security/Privacy
→ Performance/Ops
→ Cross-platform
→ Staging
→ UAT
→ Production
→ Post-launch

最终目标：
上海中心城区试点 Beta。
