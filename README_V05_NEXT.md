# v0.5 ZCode 续跑升级包

这是给**现有本地 RC 仓库**使用的 overlay，不是新项目 starter。

## 使用
1. 解压 ZIP。
2. 把里面文件复制到现有仓库根目录。
3. 不删除现有 `FINAL_RELEASE_REPORT.md`、原 `GOAL.md`、`AGENTS.md`。
4. 用 ZCode 打开现有仓库。
5. 将 `ZCODE_CONTINUE_PROMPT_v0.5.md` 全文发给 ZCode。
6. 让它持续执行。
