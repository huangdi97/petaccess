## 1. 服务内容

本产品提供「已收录来源中关于场所宠物准入规则的整理、展示与查询」，包含：规则查询、分区说明、来源与核验时间展示、用户结构化贡献、纠错与申诉入口。

本产品**不提供**：场所评价、评分、排名、社交动态、遇宠率、交易撮合。

## 3. 用户贡献规范

用户可通过结构化表单提交：规则仍然有效 / 规则已变化 / 现场告示照片 / 已知规则 / 现场经历。

用户承诺：
1. 提交内容真实，不虚构规则，不伪造来源；
2. 上传照片须为本人拍摄或已获授权，不侵犯他人肖像权、著作权；
3. 不提交与宠物准入无关的内容，不发布人身攻击、歧视性、违法内容；
4. 不使用侮辱性、价值评判性措辞描述场所或人群；
5. 不绕过技术措施批量提交。

**平台有权对贡献进行审核、编辑、拒绝或删除，并无义务全部采用。**
